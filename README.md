# GB Web Conseil — Charte graphique

Démo interactive du design system : couleurs, typographie, composants UI.

**Le design system  :** <https://geraldb69.github.io/gbwc_brand_design_system_demo/>

**Le site final :** <https://gbwebconseil.fr/>

## Fichiers


| Fichier              | Rôle                      |
| -------------------- | ------------------------- |
| `index.html`         | Homepage                  |
| `styles.css`         | Styles et variables       |
| `theme.js`           | Thème clair / sombre      |
| `components-demo.js` | Comportements interactifs |
| `assets/`            | Ressources (Logos,...)    |


## En local

```bash
python3 -m http.server 8080
```

Puis ouvrir <http://localhost:8080>
